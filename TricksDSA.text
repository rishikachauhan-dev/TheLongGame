Check Time Complexity:  n < n log n < n^2
Loop in loop → O(n²)
One pass + dict → O(n)
Sorting + one pass → O(n log n)
Check Space Complexity — are you storing extra arrays/maps?


Bonus: Debug Smart, Not Long
When stuck, always check in this order:
Variable initialization — wrong start value (-1 vs 0)
Loop range — off-by-one or indentation error
Return placement — missing return gives None
Condition direction — < vs <=
These 4 cause 90% of logic bugs.
